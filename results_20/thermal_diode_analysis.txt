--- Step 1: does this repo's model have a mechanical-switching frequency ceiling for a diode to relax? ---
core/optimize.py's NSGA-III search-space frequency upper bound is 5.0 Hz.
AMRSystem itself (core/amr_cycle.py) has NO internal frequency ceiling: frequency only ever enters W_eddy~f^2 and W_hys~f (both monotonic, uncapped parasitic-loss terms), never a hard cutoff on cooling_capacity() or magnetic_work().
No comment, docstring, or ROADMAP.md entry ties the 5.0 Hz optimize.py bound to a mechanical-valve-switching limit specifically -- it is an unexplained round-number search-space bound, not a physical constraint this module can relax.

--- Conclusion ---
The (illustrative, unbenchmarked) actuation switching-power cost in DEFAULT_MECHANICAL_CONTACT_DIODE reduces COP_electrical by at most 0.03% across the frequencies swept here -- a small effect relative to the eddy-current/base-overhead losses that already dominate W_parasitic at this operating point, because the illustrative actuation_energy_J_per_cycle=0.05J is small. This module deliberately does NOT model any offsetting heat-transfer benefit from the diode's rectification_ratio (no closed-form relation for how rectification ratio would improve AMR cycle performance was available to digitize -- see honesty flag), so net COP_electrical is <= the no-diode baseline by construction here; this is a documented cost-only accounting, not a claim that real mechanical-contact thermal diodes are a net negative for AMR performance. Step 1 additionally found that this repo's model has NO internal mechanical-switching frequency ceiling for a diode-assisted design to relax in the first place -- the only frequency bound anywhere (optimize.py's NSGA-III search bound) is an unexplained round number, not a physical constraint. No benchmark device in this repo's corpus uses thermal diodes, so none of this is validated against real hardware -- treat this module as a design-exploration tool, exactly the disposition the Phase 18 plan itself recommended for this item, not a validated feature.
